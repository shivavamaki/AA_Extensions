ชุดไฟล์ BAT ระบบ BKN Pharmacy Portal
เอกสารประกอบการพิจารณาอนุญาตใช้งานภายในฝ่ายเภสัชกรรม

1. วัตถุประสงค์และขอบเขต
รวบรวมไฟล์ .bat ทั้งหมดที่พบในโฟลเดอร์ pharmacy_server จำนวน 10 ไฟล์
คงโครงสร้างโฟลเดอร์และเนื้อหาไฟล์ต้นฉบับ พร้อมคำอธิบายภาษาไทย
ไฟล์ .bat เป็นข้อความคำสั่งสำหรับ Windows ซึ่งเรียกโปรแกรมและเปลี่ยนแปลงไฟล์ได้
ชุดนี้เป็นเอกสารและสคริปต์สำหรับตรวจสอบ ไม่ใช่ชุดติดตั้งระบบที่สมบูรณ์
ไม่ได้รวม Python, โปรแกรม .py, ส่วนขยาย Chrome หรือข้อมูลระบบ
การจัดทำ ZIP ไม่ได้เรียกใช้งานสคริปต์หรือทดสอบการทำงานกับเครื่องแม่ข่าย

2. รายการไฟล์และการทำงานทางเทคนิค
เส้นทางทั้งหมดด้านล่างอ้างอิงจากภายใน ZIP

2.1 pharmacy_server/start_server.bat
หน้าที่: เปิดบริการระบบบนเครื่องแม่ข่าย
เทคนิค: ค้นหา py, python หรือ Python 3.10–3.13 ในตำแหน่งติดตั้งของผู้ใช้
แล้วเรียก bkn_ks_server.py ที่อยู่โฟลเดอร์เดียวกับสคริปต์ ส่งต่ออาร์กิวเมนต์ทั้งหมด
ต้องมี Python และไฟล์โปรแกรมที่เกี่ยวข้อง เมื่อโปรแกรมจบจะหยุดรอให้กดปุ่ม

2.2 pharmacy_server/start_dashboard.bat
หน้าที่: เปิดบริการระบบพร้อมแดชบอร์ดในเว็บเบราว์เซอร์
เทคนิค: ใช้ python เรียก bkn_ks_server.py ในหน้าต่างใหม่ รอ 2 วินาที
แล้วเปิด http://127.0.0.1:8765/dashboard รองรับอาร์กิวเมนต์ --port
ต้องเรียก python ได้จาก PATH และมีไฟล์โปรแกรมในตำแหน่งที่กำหนด
การรอ 2 วินาทีไม่ใช่การตรวจว่าบริการพร้อมใช้งานจริง

2.3 pharmacy_server/publish_extension.bat
หน้าที่: เตรียมชุดส่วนขยายเวอร์ชันปัจจุบันให้พร้อมดาวน์โหลด
เทคนิค: ใช้ PowerShell เรียก http://127.0.0.1:8765/api/ext-version
แล้วดาวน์โหลด /ext-download ลงไฟล์ชั่วคราว เพื่อให้เซิร์ฟเวอร์สร้างหรือใช้ ZIP ที่แคชไว้
แสดงขนาดไฟล์และลบไฟล์ชั่วคราว ต้องเปิดบริการบนเครื่องนั้นก่อน
สคริปต์นี้ไม่แก้ไขหมายเลขเวอร์ชันเอง ผู้ดูแลต้องปรับเวอร์ชัน manifest.json ก่อนเผยแพร่
URL 127.0.0.1 หมายถึงเครื่องที่กำลังรันสคริปต์ ไม่ใช่ที่อยู่สำหรับส่งให้เครื่องอื่น

2.4 pharmacy_server/www/BKN-Update-Extension.bat
หน้าที่: ตัวเรียกปรับปรุงส่วนขยายสำหรับเครื่องบุคลากร
เทคนิค: ใช้ PowerShell ดาวน์โหลด http://10.134.110.81:8765/ext-sync.bat
เก็บที่ %TEMP%/bkn-ext-sync-boot.bat จากนั้นใช้ call เรียกทำงาน
ลบไฟล์ชั่วคราวและส่งคืนรหัสผลลัพธ์ของสคริปต์ที่ดาวน์โหลด
หากติดต่อเซิร์ฟเวอร์ไม่ได้จะแสดงข้อความและหยุด
ขั้นตอนปรับปรุงจริงขึ้นอยู่กับสคริปต์ที่เซิร์ฟเวอร์ส่งมา ณ เวลาที่ใช้งาน
ไฟล์ ext-sync.bat ที่ดาวน์โหลดขณะใช้งานไม่ได้รวมอยู่ในชุดนี้

2.5 pharmacy_server/www/bkn-install.bat
หน้าที่: ติดตั้งหรือปรับปรุงส่วนขยาย Chrome บนเครื่องบุคลากร
เทคนิค:
- อ่านเวอร์ชันจาก http://10.134.110.81:8765/api/ext-version
- เทียบกับ manifest.json ใน D:/pharmacy/BKNPharmacyPortal
- หากเวอร์ชันเท่ากันจะข้ามการติดตั้งและเปิดหน้าคำแนะนำ
- ดาวน์โหลด /ext-download ลง %TEMP%/bkn-ext-install
- ใช้ Expand-Archive แตก ZIP และตรวจว่ามี manifest.json
- ลบโฟลเดอร์ติดตั้งเดิม สร้างใหม่ แล้วใช้ robocopy /E คัดลอกไฟล์
- ถือว่า robocopy ล้มเหลวเมื่อรหัสผลลัพธ์ตั้งแต่ 8 ขึ้นไป
- ค้นหา Chrome และโปรไฟล์ล่าสุด แล้วเปิด /reload-extension บนเซิร์ฟเวอร์
- หากรันจากโฟลเดอร์ติดตั้ง จะคัดลอกตัวเองไป TEMP แล้วเปิดตัวสำเนาก่อน
ต้องมีไดรฟ์ D: สิทธิ์เขียนตำแหน่งติดตั้ง PowerShell และการเชื่อมต่อเซิร์ฟเวอร์
ครั้งแรกต้องเปิด Developer mode และ Load unpacked ใน Chrome ด้วยตนเอง
หลังอัปเดตผู้ใช้ยังต้องกด Reload ของส่วนขยายตามคำแนะนำ

2.6 pharmacy_server/pharmacy_server/start_server.bat
สำเนาในโฟลเดอร์ซ้อน ใช้หลักการเดียวกับข้อ 2.1
จะเรียก bkn_ks_server.py ในโฟลเดอร์ซ้อนที่สคริปต์นี้อยู่

2.7 pharmacy_server/pharmacy_server/start_dashboard.bat
สำเนาในโฟลเดอร์ซ้อน ใช้หลักการเดียวกับข้อ 2.2
จะเรียกโปรแกรมเซิร์ฟเวอร์จากโฟลเดอร์ซ้อน

2.8 pharmacy_server/pharmacy_server/publish_extension.bat
สำเนาในโฟลเดอร์ซ้อน ใช้หลักการเดียวกับข้อ 2.3
ติดต่อบริการบน 127.0.0.1:8765 เช่นเดียวกัน

2.9 pharmacy_server/pharmacy_server/www/BKN-Update-Extension.bat
สำเนาในโฟลเดอร์ซ้อน ใช้หลักการเดียวกับข้อ 2.4
ดาวน์โหลดสคริปต์จาก 10.134.110.81:8765 เช่นเดียวกัน

2.10 pharmacy_server/backup_files/start_dashboard.bat
หน้าที่: ตัวเปิดแดชบอร์ดแบบโปรแกรมเดสก์ท็อปในโฟลเดอร์สำรอง
เทคนิค: ใช้ where ตรวจหา pythonw และเรียก maprang_app.py ที่อยู่โฟลเดอร์เดียวกัน
หากไม่มี pythonw จะใช้ python แทน และส่งต่ออาร์กิวเมนต์ทั้งหมด
เป็นตัวเปิดโปรแกรมเดสก์ท็อป ไม่ใช่ตัวเปิดหน้าเว็บตามข้อ 2.2
ต้องมี maprang_app.py และ dependencies ที่โปรแกรมนั้นต้องใช้

3. ลำดับใช้งานตามบทบาท
ผู้ดูแลเครื่องแม่ข่าย:
เตรียม Python และไฟล์ระบบ แล้วเลือกเปิด start_server.bat หรือ start_dashboard.bat
เมื่อแก้ส่วนขยาย ให้ปรับหมายเลขเวอร์ชันก่อน แล้วใช้ publish_extension.bat
บุคลากร:
เก็บตัวติดตั้งหรือตัวปรับปรุงไว้ในเครื่องที่ได้รับอนุญาต
เชื่อมต่อเครือข่ายโรงพยาบาล เรียกไฟล์ และดำเนินการใน Chrome ตามหน้าคำแนะนำ
ไม่จำเป็นต้องเรียกทุกไฟล์ใน ZIP และไม่ควรเปิดตัวเรียกเซิร์ฟเวอร์ทั้งสองซ้ำกัน
โฟลเดอร์ซ้อนและ backup_files ถูกเก็บไว้เพื่อให้รายการตรวจสอบครบถ้วน
ควรยืนยันกับผู้ดูแลว่าโฟลเดอร์ใดเป็นชุดใช้งานจริงก่อนเลือกใช้
