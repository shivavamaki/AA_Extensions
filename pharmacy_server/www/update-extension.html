วิธีติดตั้ง · How to install

  1. กดปุ่ม “ดาวน์โหลดตัวติดตั้ง” ด้านบน
    ไฟล์ bkn-install.bat จะถูกบันทึกไว้ในโฟลเดอร์ Downloads ของเครื่องคุณ
    The file is saved to your own Downloads folder.
  2. เปิดโฟลเดอร์ Downloads แล้ว ดับเบิลคลิก ไฟล์นั้น
    ถ้า Windows ถามเรื่องความปลอดภัย ให้เลือก More info → Run anyway
    If Windows asks, choose More info → Run anyway.
  3. รอจนขึ้นข้อความ “Updated to version …”
    ตัวติดตั้งจะดาวน์โหลด ตรวจสอบ แล้วติดตั้งลงที่ D:\pharmacy ให้เอง
    The installer downloads, verifies, then installs to D:\pharmacy by itself.
  4. Chrome จะเปิดขึ้นมา — กดปุ่ม รีโหลด ↻ ของส่วนขยาย
    แล้วปิดแท็บนั้นได้เลย เป็นอันเสร็จ
    Press the extension’s reload arrow, then close the tab. Done.
ทำไมต้องดาวน์โหลดมาไว้ที่เครื่องตัวเอง?
สคริปต์ที่วางอยู่บนไดรฟ์ที่ใช้ร่วมกัน ใครก็ตามที่เขียนไฟล์ในโฟลเดอร์นั้นได้ สามารถแก้ไขไฟล์นั้น แล้วโค้ดจะทำงานบนทุกเครื่องที่เปิดมัน การเก็บสำเนาไว้ที่เครื่องตัวเองจึงปลอดภัยกว่า

Why download it instead of running it from the shared drive? A script on a share can be replaced by anyone who can write to that folder, and would then run on every workstation that launches it. Your own local copy removes that risk.
