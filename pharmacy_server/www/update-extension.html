วิธีอัปเดต · How to update

  1. ดาวน์โหลด ZIP แล้วแตกไฟล์ในโฟลเดอร์ชั่วคราว · Download and extract
    ใช้ Extract All และตรวจว่ามี manifest.json ก่อนเปลี่ยนไฟล์เดิม
    Extract All into a temporary folder. Confirm it contains manifest.json before changing the installed folder.
  2. ปิดหน้าส่วนขยาย แล้วแทนที่ไฟล์ในโฟลเดอร์เดิม · Replace the installed files
    สำรองไฟล์เดิมไว้ก่อน แล้วแทนที่เนื้อหาทั้งหมดของ D:\pharmacy\BKNPharmacyPortal (หรือตำแหน่งที่ติดตั้งเดิม) ด้วยไฟล์ที่แตกแล้ว ห้ามซ้อนโฟลเดอร์เพิ่ม
    Close extension pages. Back up the existing files, then replace all contents of the existing installation folder with the extracted files. Keep the same folder path; manifest.json must sit directly inside it.
  3. เปิด chrome://extensions แล้วกด Reload ↻ · Reload the extension
    พิมพ์ chrome://extensions ในช่องที่อยู่ เปิด Developer mode แล้วกด Reload ของ BKN Pharmacy Portal ตรวจว่าเป็นเวอร์ชันเดียวกับด้านบน
    Type chrome://extensions into the address bar, enable Developer mode, reload BKN Pharmacy Portal, and check its version matches the published version above.
  4. รีเฟรช ArcusAir ทุกแท็บ · Refresh ArcusAir tabs
    ปิดใบยาที่เปิดค้าง แล้วเปิดใบใหม่จากผู้ป่วยที่เลือก ตรวจ HN ก่อนพิมพ์
    Close previously opened medication sheets. Refresh ArcusAir tabs and open a fresh sheet for the selected patient; verify the HN before printing.
ติดตั้งครั้งแรก · First installation: Extract the ZIP into D:\pharmacy\BKNPharmacyPortal, then use Developer mode → Load unpacked in chrome://extensions and select that folder.

ไฟล์อัปเดตเก่า · Old updater files: Remove old BKN-Update-Extension.bat and bkn-install.bat copies from your Desktop or Downloads. These scripts are retired; use this ZIP page for future updates.
