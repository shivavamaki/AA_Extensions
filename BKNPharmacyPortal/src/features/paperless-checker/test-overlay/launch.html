BKN PAPERLESS CHECKER · SEPARATE TEST OVERLAY

Test on your ArcusAir workbench

This adds a floating role selector and scanner receiver to ArcusAir. Close any older overlay first and replace its bookmark with the updated teal button. It does not change the original extension.

  1. Show Chrome's bookmarks bar with Ctrl+Shift+B.
  2. Drag the teal button below onto the bookmarks bar.
  3. Switch to the existing ArcusAir dispense workbench tab and click that bookmark.
  4. Choose First check for Ordered only, or Second pharmacist for Allocated, Partial Checkedin, Partially Allocated, Partially Cancelled, Partially Dispensed.
  5. Search runs automatically. In second pharmacist mode, scan a prescription beginning I, O, or E. It fills Order Number, searches, and opens the matching first row. Scans submit automatically. Medicine codes mark matching rows; after every row is checked, the enabled Dispense button is clicked once. The next Dispense page is checked for the same prescription and codes, then its final Dispense button is clicked once. When ArcusAir returns to the workbench, the overlay clears the old order and waits for the next scan. The scanner keeps focus while ready, except while an ArcusAir dialog or selector is open.
