⚡ Quick Start
1
Pin the Extension
คลิก 🧩 Extensions icon บน Chrome toolbar แล้ว pin BKN Pharmacy ไว้
2
คลิก Icon เปิด Popup
คลิก Icon ⚕ บน toolbar เพื่อเปิด popup หลัก — เลือก tab ที่ต้องการ
3
Right-click เพื่อ Welcome
คลิกขวา icon เพื่อเปิดหน้า Welcome / About นี้ได้ตลอดเวลา
4
IPD Queue — เปิด arcusair ก่อน
เปิด arcusair.bdms.co.th ใน tab ไว้ก่อน แล้วกด ↻ Refresh ใน popup tab IPD Queue
5
IV Sticker
ไปที่ tab Assistant แล้วคลิก "All IV Sticker" เพื่อเปิดระบบพิมพ์ label
6
Report
ไปที่ tab Report → ใส่ date range → Generate URL แล้ว load XLS → Export PDF
